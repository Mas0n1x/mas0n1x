### About

Solo founder & developer focused on **security**, **local-first apps** and **local AI** — systems that run on your own hardware and respect your privacy.

- Building the **LawNet** ecosystem (CAD/MDT for FiveM roleplay servers) — live at [lawnet.sale](https://lawnet.sale)
- Working on **Jarvis**, a fully offline AI voice assistant
- Into Linux self-hosting, Docker and clean, maintainable architecture

### Projects

| Project | What it is | Stack |
|---|---|---|
| **[LawNet](https://lawnet.sale)** | Modular CAD/MDT platform for FiveM roleplay (police, EMS, justice, dispatch) | Node.js · React · TypeScript · SQLite |
